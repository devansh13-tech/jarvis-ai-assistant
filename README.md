# 🤖 Jarvis AI Assistant

A Python-based voice assistant built step by step while learning Python and AI.

## 🚀 Features

### ✅ Milestone 1 – Voice Assistant Basics

* Text-to-Speech using `pyttsx3`
* Time-based greetings
* Modular code using functions

### ✅ Milestone 2 – Speech Recognition

* Audio recording using `sounddevice`
* Save recordings as `.wav`
* Speech-to-Text using `faster-whisper`
* Wake word detection ("Hey Jarvis")
* Command listening
* Basic error handling

## 🛠️ Technologies Used

* Python
* pyttsx3
* sounddevice
* soundfile
* faster-whisper
